Sobre o armazenamento

Os dados ficam no navegador deste aparelho. Não há sincronização entre dispositivos não há senha nem criptografia (quem usar este navegador vê tudo) e não há backup automático: limpar os dados do navegador, trocar de aparelho ou usar uma aba anônima perde ou esconde os lançamentos. O backup em JSON ajuda, mas não substitui um banco de dados profissional.
