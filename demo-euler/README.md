# Demonstração JM Financeiro — Euler (somente dados fictícios)

Esta página é uma **prévia visual independente**. Não é o aplicativo JM Financeiro original, não se conecta à API, não possui login real e não salva movimentações.

## Como testar no celular

1. Acesse o arquivo `demo-euler/index.html` nesta ramificação de desenvolvimento.
2. Baixe o arquivo HTML pelo GitHub e abra-o no navegador do celular (Chrome ou navegador de arquivos).
3. Faça lançamentos **fictícios** e confira o saldo demonstrativo.
4. Toque em **Reiniciar demonstração** para restaurar os exemplos.

Se o GitHub exibir apenas o código-fonte, isso é esperado: o arquivo ainda **não está hospedado como site**.

## Limitações e segurança

- A página não tem autenticação, por isso **não deve ser publicada com dados reais**.
- O repositório é público; a palavra “Euler” no título indica o público do piloto, não um controle de acesso.
- Nenhum dado é transmitido a servidores pela página; os lançamentos ficam apenas na memória da aba.
- Recarregar a página restaura os valores fictícios.
- A integração com o aplicativo instalado e o futuro agente ChatGPT ainda não foi implementada.
